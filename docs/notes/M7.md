# M7 — Produit

## Choix

- Streamlit fournit une interface légère lisible depuis le warehouse DuckDB.
- L'application utilise exclusivement les tables finales M5/M6, sans accès direct au lake ou aux modèles staging.
- Les vues couvrent la saison, les joueurs et la qualité des données.

## Constats

- Séparer l'interface des sources brutes rend le produit portable et évite les règles métier dupliquées.
- Les écarts sont présentés depuis `rpt_reconciliation`, pas masqués dans l'interface.

## Limites

- Une authentification, une API ou une publication cloud dépassent le périmètre local du projet.
- Les données doivent être construites par dbt avant le lancement du dashboard.
