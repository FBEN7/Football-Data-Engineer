# M4 — Rapprochement des joueurs

## Choix

- Les candidats sont bloqués par match, équipe canonique et numéro de maillot; les noms ne créent pas les liens.
- La similarité Jaro-Winkler est conservée comme mesure de contrôle pour examiner les liens faibles.
- Un joueur doit obtenir le même identifiant Transfermarkt dans tous les matchs où il apparaît.

## Constats

- Cette clé contextuelle évite les homonymes comme « Dudu » chez Transfermarkt.
- Les alias entre noms de naissance et noms d'usage peuvent réduire la similarité sans remettre en cause un lien confirmé par le contexte.

## Limites

- Les erreurs de numéro de maillot ou de composition d'équipe peuvent empêcher un lien.
- Les 10 liens les plus faibles devront être revus dans le jeu de données complet avant conclusion finale.
