# M2 — Table de correspondance des équipes

## Choix

- J'ai maintenu 18 lignes, une par club du championnat 2023/24.
- Le nom canonique est une convention du projet; les identifiants StatsBomb et Transfermarkt ainsi que le nom football-data sont conservés séparément.
- Les correspondances douteuses ou divergentes sont maintenues manuellement: `M'gladbach`, `Ein Frankfurt`, `FC Koln` et `Heidenheim`.

## Constats

- Les noms des fournisseurs ne sont pas suffisants pour une jointure automatique fiable: abréviations, noms d'usage et absence d'espaces sont courants.
- Le seed est une table de référence de maîtrise des données; les tests vérifient l'unicité, la complétude et l'existence de chaque identifiant dans les tables staging.

## Limites

- Cette correspondance vaut pour la saison étudiée. Une évolution de club, de nom ou d'identifiant nécessiterait une maintenance explicite.
- La responsabilité opérationnelle reviendrait idéalement à une équipe référentielle, avec revue sur les nouvelles entités et les changements de source.
